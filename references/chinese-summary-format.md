# 中文文献总结与论文式排版

本规范用于视频制作前的文献阅读总结，不将总结包装为原创研究论文。以下是本项目默认格式，不代表任何学校、期刊或国家标准；用户提供的正式模板和明确要求优先。

## 语言、证据与结构

- 中文和英文输入一律先生成中文总结。标题可使用经核对的中文译名，同时保留原文标题；作者、期刊、DOI 和参考文献中的原始题名不擅自翻译或改写。
- 正文以连贯的学术段落组织，先解释概念再展开分析；不用零散要点堆叠代替论文式正文。
- 开头注明“文献阅读总结”、总结对象、实际阅读范围及来源。仅有摘要时明确标为“基于摘要”，相应章节标明信息未提供，不生成虚构的完整研究。
- 默认结构为：标题与原文信息、摘要、关键词、1 引言、2 核心方法或理论框架、3 主要结果或核心论证、4 讨论与局限、5 结论、参考文献。综述可将方法和结果调整为主题脉络与研究进展；理论论文可使用假设、推导和命题，不强行添加实验章节。
- 摘要独立概括研究问题、方法、核心发现和局限；关键词选取 3–5 个。正文长度以覆盖关键证据和适合学习为准，不受最终视频旁白字数限制。
- 使用“原文提出”“作者报告”等表述保持归属；区分原文结论、总结者解释和待核实内容。不添加原文没有的实验、创新、显著性、对比数据或参考文献。

## 页面与段落默认值

使用 `summary.md` 保存可读正文，使用 `summary.tex` 实现物理排版；两者内容需一致。Markdown 不能承诺字号、页边距和行距已经生效。

| 项目 | 默认值 |
| --- | --- |
| 纸张与页边距 | A4，四边 25 mm，单栏 |
| 正文 | 中文衬线字体，小四号（12 bp）；拉丁文字使用配套衬线字体 |
| 字体实现 | 模板使用可分发的 Fandol 中文字体与 TeX Gyre Termes 拉丁字体；指定宋体等字体时先确认已安装 |
| 段落 | 两端对齐；正文首行缩进 2 个汉字；段前、段后 0；1.5 倍行距，不用空行和空格模拟间距 |
| 标题 | 论文题名居中加粗，二号；一级标题四号加粗，二级标题小四号加粗，按 1、1.1 编号 |
| 标题间距 | 一级标题段前 12 bp、段后 6 bp；二级标题段前 6 bp、段后 3 bp |
| 页码 | 页面底部居中，连续编号 |

摘要、参考文献、公式和图表按其各自环境排版，不强行使用正文首行缩进。不得通过连续回车、手动空格或截图公式来制造外观。

## 标点、符号与单位

- 中文叙述使用中文全角标点，英文名称、DOI 和数学表达内部保留相应的半角符号。不要对公式或 URL 进行全局标点替换。
- 中文与拉丁字母交界的视觉间距由排版引擎处理，不手工插入多个空格；英文单词间保留正常空格，中文标点前后不人为增加空格。
- 首次出现缩略语时给出中文解释与英文全称；全文统一译名、缩写和符号，但不改变原文变量的定义。
- 使用真正的数学负号、乘号、上下标与希腊字母；变量、向量、矩阵、算子和单位使用可区分且与原文一致的数学样式。不得把字母 `x`、连字符或字母 `O` 随意当作乘号、负号或数字零。
- 在数值与物理单位之间使用适当的细间距，单位用正体；角度、百分比等按所选一致样式处理。不能把不同含义的百分数与百分点混用，也不能无说明转换单位。

## 公式与图表

- 行内公式用于短表达式；关键或较长公式使用独立数学环境。保留分式、根号、上下标、求和与积分结构；多行推导按等号或关系符对齐。
- 需要在正文引用的独立公式右侧顺序编号，使用 `label` 和 `eqref` 等自动交叉引用。指出其原文公式编号，避免混淆总结编号和原文编号。
- 每个保留的关键公式说明变量、单位、假设和适用条件，检查与原文是否一致。没有必要的公式时不为形式完整而编造。
- 表格标题置于表上、图片说明置于图下，连续编号并在正文引用。表格注明单位、实验条件与来源，优先使用清晰的三线表；避免超出页边距。
- 依据原文数据重绘时注明原文定位；概念示意注明“示意”。不得从模糊截图猜测精确数据。

## 引用与输出检查

- 默认采用按首次引用顺序排列的数字引用样式，如 `[1]`；正文必要时注明原文页码、章节或图表，详细证据定位仍保留在 `evidence.md`。
- 参考文献包含实际核验的作者、题名、发表来源、年份和 DOI 或来源链接；缺失字段如实标记，不复制原论文中未阅读的文献来充数。
- 以 [排版模板](../assets/chinese-summary-template.tex) 生成源稿。模板建议使用 XeLaTeX，至少编译两次以解析交叉引用；可用时优先使用能够自动处理编译次数的构建工具。
- 有编译与渲染工具时生成 PDF，逐页检查：中文字形、字号与行距、标题层级、公式溢出、上下标、表格裁切、引用编号和分页。修复缺失字形、未定义引用与影响可读性的溢出，再声明通过。
- 无法编译时仍交付 `summary.md` 与 `summary.tex`，明确 `summary.pdf` 未生成、页面排版未验收；不能用 Markdown 预览或源代码检查代替 PDF 页面验收。
- 所有模板指导文字、空字段和示例须在真实交付前替换或删除；没有数据的可选图表、公式或章节不要留空壳。
