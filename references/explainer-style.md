# 面向理解的讲解、动画与声音

用于用户要求教学视频、技术科普或提升上一版画面与配音质量时。目标是让观众跟上推理，不以主题配色或卡片数量代替讲解设计。

## 先走通一个例子

先用一个具体困惑开场，让观众知道缺少什么信息。选一个贯穿方法的输入，在屏幕上保留同一对象：观察它经过每一步后，位置、候选集、数值或状态如何改变。讲完例子再引出正式术语与公式，然后回到论文证据和适用条件。

每个镜头回答一个问题。不要把论文摘要按章节切成十几个同构页面，也不要反复用“第一步／第二步”代替因果解释。叙事可以是：遇到问题 → 现有信息不够 → 增加一种约束 → 得到什么 → 新假设有什么代价 → 用什么证据检验。

口语先讲物体与动作，再讲名称：例如先看同一回波对应的多个可能位置，再解释“俯仰角歧义”。术语第一次出现解释含义；数字保留关键比较，在旁白中读成便于理解的形式。避免连续朗读缩写、参考文献、长公式和过细的小数。

## 动画表达关系

优先使用 `scripts/render_motion.py` 的连续对象与语音触发关键帧；基础卡片渲染器保留作快速草稿。

- 保持对象身份：同一目标、候选点、观测来源和数据流使用稳定颜色与位置关系。移动、合并、筛除、展开都应有明确含义。
- 一次突出一个变化：解释到某个约束时才引入它；排除的候选点退暗，确认的位置变亮。不要为了保持“动感”让所有对象持续摆动。
- 保留整体结构，需要时局部强调；用空间位置、连线或时序表达对应关系，避免所有概念都写进并排矩形。
- 长讲解保留简洁的章节定位；返回整体图时沿用原来的对象和位置。比较方法时一次只改变正在讨论的条件或指标，以前后状态或同尺度并排图支持取舍。
- 动作时间参考实际语音边界。短暂出现与移动通常在0.3—1秒内完成，推理所需的观察过程可更长；不硬性要求每几秒切镜。
- 关键结果先讲坐标与单位，再揭示差异；对比统一尺度和基线。示意、原文数据重绘与实测图像必须可区分。
- 原文图先保留全貌与方法标签，再做必要裁切或高亮；高亮应指向正在讲的部位。截图文字不可辨认时应重绘可核验数据，不能只把整页论文缩在中央。

制作前先询问分辨率与帧率，按用户当前任务的选择输出；规格未确定时先完成文献阅读和中文总结。静态部分允许重复画面，运动部分按选定帧率的每个帧时间点重新计算位置。性能不足时说明取舍，重新询问后再调整规格。矢量轮廓必须开启覆盖抗锯齿，保留浮点位置、圆角与端点。细线在最终播放尺寸仍须清楚。原文图应从PDF高分辨率重取。

背景使用低对比渐变和稳定的明暗分层，把注意力留给讲解对象。柔和光照、局部舞台和留白都应克制；不使用持续漂浮的粒子、强噪点、抢眼纹理或变化的背景来制造“高级感”。标题、来源和字幕保持安全边距。

屏幕标题一句短问题；舞台留给解释对象。字幕以短分句为主，置于画面下部安全区域，避免黑色大字幕框挤压主体。来源可用小字定位，完整证据保留在独立记录中。

## 声音按质量选择

先制作20—40秒试听，内容应含设问、转折、数字与一个术语。选择自然、清晰且符合用户偏好的音色。沉稳中文男声可从神经音色 `zh-CN-YunxiNeural` 开始比较，`zh-CN-YunyangNeural`更偏播报；实际以试听为准，不保证一个音色适合所有任务。

可选在线路径 `scripts/synthesize_neural.py` 用整段镜头讲稿合成，保留上下文韵律，并保存服务返回的句子边界。它仅把讲稿发给Microsoft在线语音服务；涉及非公开材料时，应使用已授权的路径或本地音频。不要在失败时静默切回系统朗读音色并宣布声音升级。

默认语速接近自然对话，允许小幅调整。设问后留理解空间，转折前短停顿；重要结论通过句式和语气突出，避免整片每句话都同样重读。响度归一化只用于改善音量，不能把降调或提速当作自然度修复。背景音乐与音效可省略；声音不应妨碍理解。

中文讲稿先按说话逻辑改写：短句讲清一件事，用“先看”“那问题来了”“再加一个条件”串起推理，避免把“本文提出、进一步、综上所述”逐句照读。数字按中文表达朗读，术语出现时给一句解释。默认神经配音使用稳重男声、语速−6%，中文节奏配置补足普通句约180毫秒、问句约320毫秒的句间停顿，同时重算字幕和动画触发时间；这些只是初始值，仍需试听。

处理杂音先区分持续底噪、合成音色的金属感与衔接处爆音。更换音色可改善合成伪影；降噪不能保证修复声码器问题，强FFT降噪还可能增加金属感。默认仅作温和的低频/超高频过滤。保留PCM中间稿，按精确样本数拼接整条旁白，在整片上做一次双遍响度处理，最后一次性编码AAC；不要逐镜有损编码再拼接。在线TTS原始源目前为24kHz/48kbps MP3，转成48kHz WAV不会恢复已丢失的源细节。交付可附WAV试听，便于区分源语音与成片压缩问题。

该脚本的句子时间由语音服务提供；句内字幕分句按字数分配，是近似位置，不宣称逐字强制对齐。需要更精确时使用已有对齐工具或逐段人工校正。更改讲稿、音色或语速后重建对应音频和时间轴。

## 验收与参考研究

教学图解先检查内部规则：被排除的候选必须确实违反显示的约束或统计规则；证据不足时保留多个解。传感器、机械臂末端和视线等相连对象必须共同变换。用真实字幕时刻抽查中间运动状态，不能只看动作结束后的封面。关键机制至少走通一个可复述的输入到输出例子；示意数字、坐标与测量结果清楚区分。原文密集图表先总览，再按讲解顺序放大相关局部，并注明不同视角或比例的限制。

检查实际成片中动作是否发生在相关旁白附近；完整看一次新机制如何进入、运行和退出。试听至少开场、数字密集段、术语段和结束，记录具体范围，不能以音轨存在或音量检测代替听审。无法主观听审时明确保留待办，不宣布音质已验收。

参考创作者时，记录账号、链接、观察时间点与研究范围；区分目录核对、画面抽样、片段观看、全文字幕阅读和全片视听。作品数量多时可以建立研究清单，但不能把抽样写成看完所有作品。提炼可迁移的教学与动画方法，使用自己的脚本和素材；配音用独立音色，不以模仿个人声纹作为默认优化方式。
